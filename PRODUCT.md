# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

The learner selected a portable study guide that opens directly without a server. The implementation uses static HTML/CSS/JavaScript and a development-only Python Markdown build. The course's Python/dlt/MySQL/ClickHouse/dbt/Dagster/Streamlit/Reflex stack is taught content, not the website runtime.

## Users

A learner with basic Python and SQL, studying 6–8 hours weekly to become job-ready in data engineering.

## Product Purpose

Make the 20-week ice cream factory warehouse/pipeline syllabus readable, visual, and practical through architecture explanations, code excerpts, milestone gates, and retrieval practice.

## Capabilities and Constraints

All 20 weeks remain grounded in SYLLABUS.md. The user requested HTML visualizations and code snippets and selected portable HTML over a hosted course app. The guide is a portable folder, not one bundled file. It must not imply that a factory platform is already deployed or that merely opening a lesson demonstrates understanding.

## Evidence on Hand

MISSION.md, SYLLABUS.md, RESOURCES.md, NOTES.md, and the learner's stated prior knowledge. All factory data in demonstrations is synthetic. The standard-library fixture/freshness and lesson Python examples have executed in authoring checks. Windows/WSL setup remains learner-verified, and the complete requested tool stack has not been integration-tested.

## Product Principles

- Explain tool ownership and when not to use a tool.
- Prefer verified answers and recovery exercises to green execution badges.
- Reuse lesson assets and the glossary across teaching sessions.
- Keep credentials and actual application execution out of the browser guide.
