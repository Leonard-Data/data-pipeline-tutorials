# Mission: Job-ready data warehouse and pipeline architecture

## Why
Become job-ready in data engineering by building and explaining an ice cream factory analytics platform. Learn the fundamentals behind the tools, then demonstrate a working pipeline, trustworthy business metrics, deployment, monitoring, and recovery.

## Success looks like
- Explain source-to-dashboard architecture and justify each component and its alternatives.
- Build a repeatable MySQL → dlt → ClickHouse → dbt pipeline orchestrated by Dagster.
- Model factory sales, production, waste, and inventory without mixing grains or double-counting measures.
- Serve tested warehouse models through Streamlit and a small Reflex application.
- Deploy a portfolio system, detect broken or stale data, recover from failures, and demonstrate the work to an interviewer.

## Constraints
- Self-reported starting level: basic Python and SQL; warehouse and operations knowledge not yet assessed.
- Study budget: 6–8 hours per week.
- Chosen structure: milestone-based, using one evolving factory project.
- Requested stack: Python, DLT, ClickHouse, Dagster, MySQL, DBT, Streamlit, Reflex. The syllabus interprets DLT as the Python library `dlt`, and DBT as `dbt`.
- Proposed duration: 20 weeks, adjusted by demonstrated understanding rather than calendar progress.
- Setup environment: Windows / WSL, at least 16 GB RAM, Docker not installed (learner-reported). Exact OS build, CPU architecture, virtualization, and free disk space still need checking.
- Deployment budget is deferred; no paid provisioning is approved.

## Out of scope
No learner exclusions have been established. Proposed deferrals, not permanent exclusions, are listed in [SYLLABUS.md](SYLLABUS.md).
