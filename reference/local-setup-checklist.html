A local setup you can verify.

Windows / WSL 2 · Ubuntu · Docker Desktop · uv · Python 3.12 baseline. Checks only; use the lesson for installation.

Before installation

  • Record Windows edition/build, CPU architecture, virtualization, RAM, and actual host-drive free space. Compare the build/architecture with Docker’s live requirements; on Windows ARM, pause for a specific support check.
  • 16+ GB RAM is reported, not full-stack capacity proof. Course allowance: 20 GB free, not a vendor minimum. WSL capacity does not prove host free space.
  • Budget is deferred: no paid provisioning. Check Desktop licensing and administrator policy. Stop on unsupported hardware, blocked permissions, or unclear eligibility.
